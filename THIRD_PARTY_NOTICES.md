# Asset and source provenance

This repository has not been cleared for public distribution. `LICENSE` records
that no new public rights grant has been made. This maintenance task cannot
establish ownership of pre-existing code/artwork or choose the owner's license.

| Material | Treatment and known evidence |
|---|---|
| Active Python source | Existing project source plus audit repairs; ownership/license of historical contributions requires owner review. |
| `media/ferret-long-sprite.png` and `.json` | Active sheet/metadata; no original rights statement supplied. Owner must verify before redistribution. |
| `media/soupbowl.png` | Active bowl art; provenance not established. Owner must verify before redistribution. |
| `sounds/*.wav` | Generated by the repository's `generate_sounds.py`; no archived downloaded sounds are used. |
| Runtime enemy drawings | Original procedural shapes in active Python modules; the branded soup-can image is no longer used. |
| Historical Pac-Man/Centipede/Dig Dug/Boulder Dash folders | Preserved in `legacy_reference/games/`; excluded from builds. Includes a third-party executable, audio/fonts, and downloaded assets with unresolved terms. |
| `legacy_reference/games/_archive/boulderdash_legacy.py` | Carries a GPL-3.0 statement in its source. Preserve that statement; this repository notice does not replace it. |
| Other archived sources | Carry original authors' names; license/permission evidence is incomplete. |
| Archived Centipede audio | Freesound-derived filenames; no verified license/attribution records supplied. Excluded from active runtime and packaging. |
| Pygame and packaged dependencies | Retain their upstream license metadata in generated distributions. |

Display names now use Tunnel Treats, Burrow Defender, Crystal Quest and Rocky
Burrow. Historical module and save IDs remain for compatibility, without implying
an affiliation. A different name alone does not clear source or artwork rights.

Before a public release the owner must establish the missing permissions, choose
an appropriate license for material they own, and review dependency license
notices. No archive content should be added to a release merely because it is
present locally. No claims about public distribution clearance are made here.
